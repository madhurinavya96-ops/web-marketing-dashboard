# 📊 Web Marketing Analytics Dashboard

A comprehensive Web Marketing Analytics Dashboard developed using **Power BI, SQL, and Excel** to analyze website performance, customer engagement, campaign effectiveness, and conversion trends. The dashboard provides actionable insights to support data-driven marketing decisions.

---

## 📌 Project Overview

This project analyzes web marketing performance by tracking key metrics such as website traffic, campaign performance, customer engagement, and conversion rates. Interactive visualizations help identify trends, measure marketing effectiveness, and support strategic business decisions.

---

## 🛠️ Tools & Technologies

- Power BI
- SQL
- Microsoft Excel
- Data Modelling
- DAX

---

## 📈 Key Analysis

- Website Traffic Analysis
- Marketing Campaign Performance
- Customer Engagement Analysis
- Conversion Rate Analysis
- Marketing KPI Monitoring

---

## 📊 Dashboard Features

- KPI Cards
- Traffic Trend Analysis
- Campaign Performance Comparison
- Customer Segmentation
- Interactive Filters and Slicers
- Dynamic Visualizations

---

## 💡 Business Insights

- Identified high-performing marketing campaigns.
- Analyzed customer engagement and behavior trends.
- Measured website traffic and conversion performance.
- Supported data-driven marketing decision-making.
- Highlighted opportunities to improve campaign effectiveness.
